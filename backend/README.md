# Demand Prediction FastAPI Service

## 1. Setup

First, install the required python packages. From the `d:/College/DS/TS/backend` directory, run:

```bash
pip install -r requirements.txt
```

## 2. Run the Server

To start the FastAPI service, run the following command from the `backend` directory:

```bash
uvicorn main:app --reload
```

The server will start locally at: `http://127.0.0.1:8000`. 
On startup, it will load the `random_forest_model.pkl` and `label_encoder.pkl` from the `../models/` directory for fast inferences.

## 3. Endpoints

### 3.1. Health Check
Check if the service is alive and the model objects are loaded.
**Request**:
```bash
curl -X GET http://127.0.0.1:8000/health
```

### 3.2. Predict Demand
Send the features to predict demand. Notice that `is_weekend` and `peak_hour` are engineered based on the time and date features automatically.
**Request**:
```bash
curl -X POST http://127.0.0.1:8000/predict \
     -H "Content-Type: application/json" \
     -d '{"hour": 8, "day_of_week": 1, "location": "Manhattan"}'
```

**Response Example**:
```json
{
  "predicted_demand": 4.56,
  "demand_level": "High"
}
```

## 4. API Docs
Swagger UI documentation is automatically generated by FastAPI. Open your browser and navigate to:
`http://127.0.0.1:8000/docs`
